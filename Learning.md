
# MERN Stack Learning Notes

## What is MERN?
MERN stands for MongoDB, Express.js, React.js, and Node.js.

## Technologies
- MongoDB: Stores application data.
- Express.js: Handles backend routes and APIs.
- React.js: Builds the user interface.
- Node.js: Runs JavaScript on the server.

## Request-and-Response Flow
1. The user interacts with the React frontend.
2. React sends an HTTP request to the backend.
3. Express receives and processes the request.
4. Node.js executes the backend logic.
5. MongoDB stores or retrieves the required data.
6. The server sends a response to React.
7. React updates the user interface.

## Key Learning
A MERN application uses the frontend, backend, and database together to provide dynamic web functionality.
