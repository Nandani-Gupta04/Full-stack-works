
# 🎨 CSS Typography Practice

---

## 📌 About The Project

This project focuses on **CSS Typography** and includes 8 practical tasks to understand different typography properties.

The main objective is to learn font families, Google Fonts, CSS units, text styling, link states, form typography, and debugging.

---

## 🚀 Tasks Completed

### 🔹 Task 1: Font Stacks

- Created three paragraphs with different font stacks.
- Used at least three fonts in each stack.
- Applied `sans-serif`, `serif`, and `monospace`.
- Compared the appearance of different font styles.

---

### 🔹 Task 2: Google Fonts & CSS Variables

- Selected two fonts from Google Fonts.
- Used one font for headings and another for body text.
- Added Google Fonts links inside the HTML `<head>`.
- Created `--font-heading` and `--font-body` variables inside `:root`.
- Applied fonts to headings and body.
- Verified rendered fonts using Chrome DevTools.

---

### 🔹 Task 3: CSS Units (em & rem)

- Created a parent div with `font-size: 20px`.
- Applied `1.5em` and `1.5rem` to paragraphs.
- Compared the difference between `em` and `rem`.
- Nested another `1.5em` element.
- Checked computed font sizes in DevTools.

---

### 🔹 Task 4: Type Scale & Readability

- Created headings from `h1` to `h4`.
- Added three long paragraphs.
- Applied font sizes using `rem` units.
- Set body `line-height: 1.6`.
- Limited paragraph width to `65ch`.
- Tested `line-height: 1.6px` and observed readability issues.

---

### 🔹 Task 5: Text Properties

- Created a card with a title, subtitle, and paragraph.
- Applied uppercase text transformation.
- Used letter spacing, font weight, text alignment, and text shadow.
- Styled the subtitle using italic text.
- Applied `text-indent: 2rem` to the first paragraph.
- Compared font weights: 300, 400, 600, and 700.

---

### 🔹 Task 6: Link States

- Created three different links.
- Styled `:link`, `:visited`, `:hover`, `:focus`, and `:active`.
- Tested incorrect and correct selector orders.
- Understood why selector order matters when specificity is the same.

---

### 🔹 Task 7: Form Typography

- Created a form with label, input, textarea, select, and button.
- Observed default typography in form controls.
- Used `font: inherit` for consistent typography.
- Styled input placeholders using `::placeholder`.
