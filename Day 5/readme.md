
# Day 5 - Student Registration Form

## What I Built
I created a responsive Student Registration Form using HTML and CSS.

The form includes:
- Full Name
- Email Address
- Age
- Course Selection
- Study Mode (Online/Offline/Hybrid)
- Learning Goals
- Practice Data Confirmation

## Validation Checks Tested

1. Submitted the form without filling required fields.
   The browser displayed validation messages.

2. Entered an invalid email address.
   The browser prevented form submission.

## Bug Fixed

In this form there is not any bug but it could required more validation and styling..

## Why Client-Side Validation Is Not Enough

Client-side validation can be bypassed by users.
A real application also needs server-side validation
to protect data and prevent invalid submissions.

## Future Improvement

I would like to connect this registration form
to a backend database so student information
can be securely stored.
