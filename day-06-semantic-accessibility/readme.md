In Day 06, I reviewed my previously created website and improved its HTML structure and accessibility.

The main purpose of this task was to make the website more structured, user-friendly, accessible, and easy to navigate.

I checked semantic HTML elements, heading hierarchy, images, links, form labels, keyboard navigation, and responsive layout.

# 🎯 2. Learning Outcomes
Understand and use Semantic HTML elements.
Maintain a proper Heading Hierarchy.

🛠️ 3. Tasks Completed
# ✅ Task 1 – Semantic HTML Structure

Reviewed the HTML structure and used meaningful semantic elements.

Elements used:

<header> – Introductory content.
<nav> – Navigation links.
<main> – Main page content.
<section> – Related content groups.
<footer> – Footer information.

Result: Improved the structure and readability of the HTML code.

# ✅ Task 2 – Heading Hierarchy

Reviewed and organized the heading structure.

Used one clear <h1> for the main page title.
Used <h2> for major sections.
Used <h3> for subsections where required.
Maintained a logical heading order.

Result: Made the content easier to understand and navigate.

# ✅ Task 3 – Images and Links

Reviewed images and links for accessibility.

Added meaningful alt text to informative images.
Used empty alt="" for decorative images.

Result: Improved image descriptions and link accessibility.

# ✅ Task 4 – Form Accessibility

Reviewed the Day 05 practice form.

Added visible labels to form controls.
Matched for and id attributes.
Checked that all IDs were unique.
Used the required attribute
