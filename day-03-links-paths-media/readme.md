# Day 03 — HTML Links, File Paths & Media

A basic, responsive multi-page mini-site built as part of the **Tech Fellows 90-Days Program**. This project focuses on internal structural links, relative file paths, and local media integration using semantic HTML and embedded CSS styling.

## 🚀 Features
*   **Multi-Page Navigation:** Cross-linked `index.html` and `about.html` pages.
*   **Fragment Anchors:** A smooth section jump targeting specific IDs (`#projects`).
*   **Local Assets:** Relative path reference for locally stored images.

## 📂 Project Structure
```text
day-03-links-paths-media/
├── README.md
├── index.html
├── about.html
└── profile.png
    
```

## 🛠️ Setup & Local Testing
1. Clone your root repository to your local machine.
2. Navigate into the `day-03-links-paths-media` directory.
3. Open `index.html` directly inside any modern web browser to test the page navigation.
